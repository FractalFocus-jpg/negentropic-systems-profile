## 📋 Deployment Steps

### Step 1: OAuth Configuration (5-30 min)

Run the OAuth wizard to connect all services:

```powershell
cd C:\Users\alexl\Desktop\tapestry-codex-starter
.\scripts\auth\OAUTH_WIZARD.ps1
```

This will guide you through:
1. ✅ Google Services (Gmail, Calendar, Drive, Photos, YouTube)
2. ✅ TikTok (@fractalfocus)
3. ✅ Instagram (@realeyesrealizinglies)

**Manual OAuth Scripts** (if needed):
```powershell
.\scripts\auth\setup_google_oauth.ps1 -ShowInstructions
.\scripts\auth\setup_tiktok_oauth.ps1 -ShowInstructions
.\scripts\auth\setup_instagram_oauth.ps1 -ShowInstructions
```

All credentials are stored in `.env.local` (git-ignored).

---

### Step 2: Bootstrap the OS (2 min)

Initialize the OS and all agent directories:

```powershell
.\BOOTSTRAP_OS.ps1
```

This will:
- ✅ Load environment variables
- ✅ Check all paths
- ✅ Initialize agent status files
- ✅ Create first boot log

---

### Step 3: Activate Agents (1 min)

**Dry run first** (recommended):
```powershell
.\ACTIVATE_AGENTS.ps1 -DryRun
```

**Live activation**:
```powershell
.\ACTIVATE_AGENTS.ps1 -DryRun:$false
```

Agents activate in priority order:
1. Sentinel (security first)
2. Weaver → Hermes → Scribe → Ledger → Janus → Choir

---

### Step 4: Start SR-Loop (Continuous Learning)

**Single cycle** (test):
```powershell
.\scripts\SR_LOOP.ps1
```

**Continuous mode** (hourly):
```powershell
.\scripts\SR_LOOP.ps1 -ContinuousMode -IntervalMinutes 60
```

The SR-Loop:
1. **Observes**: Dashboard, agents, logs, system state
2. **Compresses**: Extracts patterns & insights
3. **Redeploys**: Updates configurations automatically

---

## 🔒 Safety & Control

### Security Settings

| Setting | Value | Purpose |
|---------|-------|---------|
| **SEC_MODE** | confirm | Human approval required for all posts |
| **DRYRUN** | true (default) | Review before publish |
| **HUMAN_OVERRIDE** | true | You have final say always |
| **ROLLBACK** | enabled | Can undo any action |
| **PII_GUARD** | active | Personal data protected |
| **TOKEN_LIMIT** | adaptive | Cost protection |

### Emergency Controls

**Emergency Stop**:
```powershell
# Create this file to halt ALL operations:
New-Item -Path "C:\Users\alexl\Desktop\tapestry-codex-starter\EMERGENCY_STOP" -ItemType File
```

**Pause Specific Agent**:
Edit `OS/agents/{AgentName}/status.json`:
```json
{
  "enabled": false
}
```

**Rollback**:
```powershell
# Sentinel maintains rollback history
.\scripts\sentinel\rollback.ps1 -ActionId <id>
```

## 📞 Support & Troubleshooting

**Dashboard Not Running**:
```powershell
# Check if Python venv is activated:
.venv\Scripts\activate
python src/tapestry/self_observing_dashboard.py
```

**OAuth Token Expired**:
```powershell
# Re-run OAuth for specific service:
.\scripts\auth\setup_google_oauth.ps1
```

**Agent Not Responding**:
```powershell
# Check status:
Get-Content "C:\Users\alexl\the living tapestry\OS\agents\{AgentName}\status.json"

# Check logs:
Get-Content "C:\Users\alexl\the living tapestry\OS\logs\$(Get-Date -Format 'yyyy-MM-dd').md"
```

**Full System Reset**:
```powershell
# Deactivate all agents:
.\ACTIVATE_AGENTS.ps1 -DryRun

# Clear .env.local and re-run OAuth:
Remove-Item .env.local
.\scripts\auth\OAUTH_WIZARD.ps1

# Reboot:
.\BOOTSTRAP_OS.ps1
.\ACTIVATE_AGENTS.ps1 -DryRun:$false
```
