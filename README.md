## 🚀 QUICK START

### 1. Initial Setup
```powershell
# Clone repository
git clone https://github.com/FractalFocus-jpg/tapestry-codex-starter.git
cd tapestry-codex-starter

# Create virtual environment (Python)
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# Install dependencies
pip install -r requirements.txt
```

### 2. OAuth Configuration
```powershell
# Run OAuth orchestration script
.\OAUTH_SETUP.ps1
```

This will guide you through:
- Google Services (Gmail, Calendar, Drive, Photos, YouTube)
- Social Media (TikTok, Instagram × 3, YouTube, Quora)
- Workspace Tools (Notion, Confluence, Linear, GitHub)
- AI Mesh (Claude, Gemini, Grok, DeepMind, Copilot)

### 3. Deploy Agents
```powershell
# Deploy all agents via Agent Kit
.\DEPLOY_AGENT_KIT.ps1

# Or activate specific agents
.\ACTIVATE_AGENTS.ps1 -agents sentinel,weaver,hermes
```

### 4. Monitor System
```powershell
# Start dashboard
.\START_DASHBOARD.bat
# → Opens http://localhost:5055

# Check status
.\STATUS_CHECK.ps1

# View alerts
Get-Content "C:\Users\alexl\the living tapestry\alerts\*.json"
```
